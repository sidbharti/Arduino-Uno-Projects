
# Traffic Light System Using Arduino

## Objective
To simulate a basic traffic light system using Arduino Uno and three LEDs.

## Components Required
- Arduino Uno
- Red LED
- Yellow LED
- Green LED
- 3 x 220 ohm resistors
- Breadboard and jumper wires
- USB cable

## Pin Connections
- Red LED: Digital Pin 8
- Yellow LED: Digital Pin 9
- Green LED: Digital Pin 10
- LED negative legs: GND through the circuit

## Working Principle
1. Red LED turns ON for 5 seconds.
2. Green LED turns ON for 5 seconds.
3. Yellow LED turns ON for 2 seconds.
4. The sequence repeats continuously.

## Skills Demonstrated
- Arduino programming
- Embedded C++
- Digital input/output pins
- Timing control using delay()

## How to Run
1. Open Traffic_Light.ino in Arduino IDE.
2. Connect Arduino Uno using USB.
3. Select Tools > Board > Arduino Uno.
4. Select the correct COM port.
5. Click Verify, then Upload.

## Result
The three LEDs operate in a repeating traffic-light sequence.
