
# LED Blinking Using Arduino

## Objective
To blink the built-in LED of the Arduino Uno.

## Components Required
- Arduino Uno
- USB cable
- Arduino IDE

## Working Principle
The built-in LED turns ON for one second
and OFF for one second continuously.

## Skills Demonstrated
- Arduino programming
- Embedded C++
- Digital output control
- GPIO configuration

## How to Run
1. Open LED_Blink.ino in Arduino IDE.
2. Connect Arduino Uno using a USB cable.
3. Select Arduino Uno under Tools > Board.
4. Select the correct COM port.
5. Click Verify and then Upload.

## Result
The built-in LED blinks continuously.
